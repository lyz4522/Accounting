# 个人消费记账 GUI

一款使用 Python、Tkinter、SQLite 和 Matplotlib 构建的本地桌面记账应用。账目保存在本机，不需要账号、云服务或网络连接。

## 功能

- **收支记录**：新增、修改和删除收入/支出，包含日期、类型、分类、金额和备注；可按日期范围、收支类型和对应分类筛选。
- **分类管理**：分别管理收入与支出分类。支持添加自定义分类；内置分类不能删除，已有记录引用的分类须先处理记录才能删除。
- **统计分析**：查看日、周、月、年收支汇总；查看月度收入/支出分类占比饼图和年度月度收支趋势图。
- **预算提醒**：按月设置预算，以“支出 − 收入”计算净消费；超出预算时弹窗提醒。净收入隐藏进度条并显示盈利金额；净消费不超过预算 50% 时显示绿色进度条，超过 50% 时显示红色进度条和余额不足提醒，超预算时红字显示超额金额。
- **本地存储**：首次启动时自动创建 `data/accounting.db`。数据库目录已加入 `.gitignore`，个人账目不会提交到 Git。

## 环境要求

- Python 3.10 或更新版本（需有受支持的 Matplotlib 发行版）
- Windows、macOS 或 Linux 桌面环境
- Python 需包含 Tk 支持（Windows 官方安装包通常已包含；Linux 可能需要单独安装 Tk 系统包）

## 安装与启动

在项目根目录创建并激活虚拟环境，然后安装依赖。

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

退出图形界面后，可运行以下命令执行测试：

```bash
python -m unittest discover -v
```

测试使用临时数据库，不会读取或修改日常使用的账目。

## 输入格式与边界

| 输入项 | 要求 |
| --- | --- |
| 日期 | 通过年份、月份、日期下拉框选择；年份范围为 1900–2100，日期随月份和闰年自动校正。 |
| 预算月份、图表月份 | 通过年份和月份下拉框选择；年份范围为 1900–2100。 |
| 统计周期 | 从日、周、月、年中选择；统计日期通过下拉框选择，周/月/年按所选日期所在周期计算。 |
| 收支类型 | 从收入、支出中选择；筛选时也可选“全部”。 |
| 分类 | 从当前收支类型的分类列表中选择。自定义名称必填，去除首尾空格后为 1–20 个字符；同类型下不能重名。 |
| 金额、预算 | 必填，使用阿拉伯数字；格式为最多 12 位整数和可选的 1–2 位小数，例如 `12`、`12.5`、`12.50`。值须大于 0，最大为 `999,999,999,999.99`；不接受负数、科学计数法、千位分隔符或超过两位小数。 |
| 备注 | 可留空；最多 100 个字符。 |
| 日期筛选 | 开始/结束日期各自勾选后生效；若同时启用，开始日期不得晚于结束日期。 |
| 趋势年份 | 从年份下拉框选择，范围为 1900–2100。 |

金额和分类名称在输入时会限制字符长度/格式；保存时业务层仍会再次校验全部边界。非法输入会显示错误提示，不会写入数据库。

## 依赖说明

`requirements.txt` 只包含应用需要额外安装的第三方包：`matplotlib>=3.7,<4.0`。Tkinter、SQLite 和其余业务模块来自 Python 标准库。`pyproject.toml` 中声明了相同的 Matplotlib 依赖及 Python 版本范围。
